## Реализация

Формат файла — `id;label;source;featureCount;status`, кодировка UTF-8. Классы в `src/main/java/edu/course/lab05/`:

- `Sample` — неизменяемая модель набора данных, предметные ограничения проверяются в конструкторе;
- `SampleStatus` — перечисление статусов `READY`, `TRAINING`, `FAILED`;
- `SampleFileLoader` — чтение файла, проверка заголовка и разбор одной строки;
- `LoadResult` — корректные объекты и список ошибок записей, списки неизменяемые;
- `ValidationError` — номер строки, имя поля и сообщение;
- `DataLoadingException` — ошибка источника с сохраненной исходной причиной.

Два вида отказа разделены:

- **ошибка источника** — файл отсутствует, недоступен, пуст или у него неверный заголовок: обработку начать нельзя, выбрасывается `DataLoadingException` (для I/O-ошибки исходное исключение сохраняется в `cause`, для неверного заголовка и пустого файла `cause` равен `null`);
- **ошибка записи** — неверное число полей, пустое поле, нечисловое значение `featureCount`, неположительное число признаков или неизвестный статус: строка пропускается, `ValidationError` добавляется в `LoadResult.getErrors()`, остальные строки продолжают обрабатываться.

Номер строки в `ValidationError` — фактический номер строки файла, пустые строки пропускаются, но счет не сбивают. Загрузчик ничего не печатает и не вызывает `printStackTrace`.

## Тесты

`src/test/java/edu/course/lab05/`:

- `NumbersFileTest` — подготовительная часть: чтение UTF-8 файла в `@TempDir`, цикл `Integer.parseInt` и `NumberFormatException` на строке `bad`;
- `SampleFileLoaderTest` — корректный файл, кириллица, пустое поле, неправильное число, неизвестный статус, неверное число столбцов, совместная обработка корректных и ошибочных строк, отсутствующий и недоступный файл, неверный заголовок, пустой файл, BOM, пустые строки;
- `LoadResultTest` — содержимое результата и неизменяемость списков.
